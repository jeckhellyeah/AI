# 🤖 AI Pribadi dengan Gemini

Chatbot AI dengan dukungan upload gambar & file, menggunakan Google Gemini API.

## ✨ Fitur
- 💬 Chat real-time dengan AI
- 📎 Upload gambar & file (PDF, TXT, DOC, dll)
- 🔑 Simpan API Key di local storage
- 📝 Custom system prompt
- 🌡️ Atur temperature (kreativitas)
- 💾 Riwayat chat tersimpan

## 🚀 Cara Deploy (GRATIS)

### Opsi 1: Vercel (Termudah)
1. Buat akun di [vercel.com](https://vercel.com)
2. Upload 3 file ini ke GitHub repository
3. Import repository ke Vercel
4. Deploy! Dapatkan URL seperti: `https://your-app.vercel.app`

### Opsi 2: Render
1. Buat akun di [render.com](https://render.com)
2. Pilih "Static Site"
3. Upload file atau connect GitHub
4. Deploy gratis

### Opsi 3: Netlify
1. Buat akun di [netlify.com](https://netlify.com)
2. Drag & drop folder project
3. Deploy!

## 🔑 Dapatkan API Key
1. Kunjungi [Google AI Studio](https://aistudio.google.com/apikey)
2. Buat API Key baru
3. Masukkan ke aplikasi

## 📱 Penggunaan
1. Masukkan API Key di sidebar
2. (Opsional) Atur prompt system
3. Mulai chat!
4. Klik 📎 untuk upload file/gambar

## ⚠️ Catatan
- File maksimal 5MB per file
- API Key disimpan di browser (localStorage)
- Support Gemini 1.5 Flash (gratis)
